Full PRD: https://www.notion.so/35ffbf3d625981a1a6aadd1787a94562

## Run Locally
```bash
pip install streamlit
streamlit run app.py
```

## Deploy Free on Streamlit Cloud
1. Push to GitHub
2. Go to share.streamlit.io → connect repo → deploy
3. No API key needed — this version uses static data

## Note
This is the static prototype version. A Claude API-powered version with real-time AI-generated content is in development.
